# Source Code From Final Report

The files in this directory reproduce the source-code appendix included in the supplied final project report.

The report's appendix does not contain every file referenced by the React application. For example, `App.jsx` imports `Dashboard`, `AddProject`, `About`, and `Contact`, but their source is not included in the supplied appendix. Backend route files are also referenced but are not included in the backend appendix excerpt.

No Solidity smart-contract source is included in the supplied report.

The code should therefore be considered a faithful report excerpt rather than a complete, independently verified build.
